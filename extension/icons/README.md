# Extension Icons

Place your icons here:
- `icon16.png` — 16x16 (toolbar)
- `icon48.png` — 48x48 (extensions page)
- `icon128.png` — 128x128 (Chrome Web Store)

You can generate these from any logo or use a simple colored square as placeholder.
For a quick placeholder, use https://placehold.co/128x128/1a1a1a/ffffff?text=SF
